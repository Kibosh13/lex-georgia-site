Preventive request

Learn about a notice before it gets in the way

Many people learn of a notice only at a border or a bank. A preventive request to the CCF lets you find out in advance whether Interpol holds data about you and prepare a defence before a trip, a transaction or a residence application.

If data is found, we move straight to a complaint. If there is no data yet but a real risk, the Commission can be sent a position on the political nature of the prosecution in advance.

When it is useful

  • Before travelling abroad
  • Before opening an account or a major deal
  • Before applying for a visa, residence or citizenship
  • If a case has been opened at home
  • If relatives are being questioned
What the request gives

Outcome of the check

Whether data exists

We learn whether Interpol’s files hold data about you and in what form: a notice, a diffusion or another record.

Content

If the source country does not object, the Commission discloses what data is held.

Risk assessment

We understand how risky a particular trip or transaction is.

Pre-emptive position

Where a notice is likely, we put the persecution arguments to the Commission in advance.

Plan

If data exists, we prepare a complaint; if not, we advise on next steps.

Confidentiality

We plan what to disclose in the request so as not to cause harm.

How we work

Stages of the request

Consultation

We review the situation at home and decide whether to file.

Preparation

We draft the request in one of Interpol’s working languages with an ID copy.

Filing

We send it to the CCF and answer the Commission’s follow-up questions.

Reply

Under CCF rules an access request is answered within 4 months.

Questions

Common questions about a preventive request

Could the request trigger a notice?

A request is not in itself a ground for a notice. But if data exists, the Commission consults the source NCB, so we plan the content carefully.

What is needed?

A passport copy, a request in English, French, Spanish or Arabic and, if needed, a power of attorney for the representative.

Can I check myself on Interpol’s website?

Only a small share of Red Notices is published. Not being on the public list does not mean there is no data.

A check is no reason to panic. It is a way to get clarity and make informed decisions about travel and documents.
